# Workflow: Larena documentation v1

Date: 2026-09-14
Status: completed

## Goal

Create a single Russian Larena documentation site on Docara for the twelve
packages in the Minimal CMS foundation and make it available locally at
`https://larena-doc.test`.

## Done When

- Docara is pinned to the latest verified stable release.
- The site explains the platform, the twelve packages, shared standards and a
  verified first learning path without presenting planned behavior as ready.
- Every public page has an audience, outcome, source basis and review status.
- The full build and static verification pass.
- The exact generated bytes are served successfully at
  `https://larena-doc.test`, including nested routes, search and assets.
- The repository contains a source map, coverage map, maintenance procedure and
  a remaining-gaps register.

## Context

- Public documentation language for this first edition is Russian.
- Larena Specs and existing package documentation retain their current language
  policy and source-of-truth ownership.
- Source revisions are frozen in the documentation source map.
- The current branch `main` is reused; no branch or worktree is created.

## Constraints And Risks

- Do not change Larena Specs, Larena package code or the Docara repository.
- Do not use uncommitted Docara checkout changes as a released runtime.
- Do not publish the site externally.
- Package readiness differs; pages must distinguish verified behavior, bounded
  developer surfaces and planned work.
- Generated `build_*` and `vendor/` are outputs and must not become authored
  documentation.
