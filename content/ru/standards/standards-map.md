# Карта стандартов

> **Для кого:** архитектор, автор пакета или компонента, ревьюер, агент.
> **Результат:** за минуту найти, какой стандарт действует, чей он и на чём
> основан. **Источник:** `larena-specs/specs/standards/map.json`; из того же
> файла собирается `larena-specs/docs/standards/standards-map.md`. При
> расхождении прав источник.

## Три места, три роли

| Роль | Где |
|---|---|
| Оригинал стандарта | у владельца: Framework — `ui-source`, Larena — `larena-specs`, форма — `ai-first` |
| Публикация | Framework — ui-doc, Larena — этот сайт |
| Рабочий набор для разработки Larena | `larena-specs`: свои стандарты плюс точные копии стандартов Framework с хешами |

Стандарты Larena не публикуются в документации Framework: Framework не должен
знать про Larena, иначе другие продукты получат чужие правила.

## Уровни

1. **Стандарт стандартов** — в какой форме пишется любой стандарт.
2. **Макет и лист** — как интерфейс собирается из JSON и что объявляет отдельный
   Smart-компонент.
3. **Композитный компонент** — несколько компонентов, которые ведут себя как один,
   только на фронтенде.
4. **Динамический композитный компонент** — композит, который читает и пишет
   через сервер.
5. **Профили Larena** — что значит конкретный вид композита в Larena.

Стандарты уровней 1–4 изданы в документации Framework, в разделе
«Стандарты» (`https://ui-doc.test/ru/standards/`): у каждого есть страница для
людей и машиночитаемая форма для ИИ (`/ai/standards/<идентификатор>/<версия>/`).

Композит «представление данных» переезжает во Framework по этапам; Larena
оставляет себе серверную сторону (хост) и профиль представления данных.

## Как это используется при разработке

- Какой стандарт действует на какой код — `larena-specs/standards.project.json`.
- Задача на пакет называет применимые стандарты в поле `standards`; с 2026-09-25
  без этого гейт не пропускает задачу.
- Соответствие подтверждается отчётом по каждому требованию; отчёт обязан
  покрывать все требования стандарта.
- Проверка — `node scripts/validate-standard-contracts.mjs` в `larena-specs`,
  входит в `npm run validate`.
