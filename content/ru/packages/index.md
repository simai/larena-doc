# Двенадцать базовых пакетов

> **Для кого:** разработчик. **Результат:** найти владельца контракта, его
> зависимости и ограничение. **Источники:** package manifests, READMEs, Specs и
> Root lock. **Статус:** проверено по ревизиям из раздела «Версии».

| Контур | Пакеты |
| --- | --- |
| Основа и конфигурация | [Core](/packages/core/), [Setting](/packages/setting/), [Lang](/packages/lang/) |
| Личность и права | [Auth](/packages/auth/), [Access](/packages/access/) |
| Данные и файлы | [Property](/packages/property/), [Storage](/packages/storage/), [Filesystem](/packages/filesystem/) |
| Представление и интерфейс | [Dataview](/packages/dataview/), [Layout](/packages/layout/), [UI](/packages/ui/), [Admin](/packages/admin/) |

Справочник описывает роли пакетов в текущем срезе. Для точных внутренних
деталей используйте документацию в соответствующем package repository.
