# Как добавить страницу или компонент

1. Найдите пакет-владелец поведения и данных.
2. Проверьте, существует ли нужный универсальный тип или слот в Framework.
   Если его нет, сначала согласуйте расширение с владельцем Framework.
3. В UI зарегистрируйте компонент, варианты, props, именованные слоты и
   необходимые ресурсы. Регистрируйте только реально поддерживаемые значения.
   Для страницы также задайте соответствие `slot → region` и серверные режимы
   области по умолчанию на уровнях сайта, раздела и страницы.
4. Реализуйте безопасный серверный renderer, чтобы содержательный HTML был
   доступен без JavaScript.
5. В Layout добавьте системный артефакт пакета или создайте пользовательский
   артефакт через `LayoutArtifactStore`. Содержимое передавайте типизированной
   ссылкой, а не HTML.
6. Добавьте положительные и отрицательные fixtures: неизвестный тип, слот,
   вариант, цикл, запрещённое поле и превышение лимита должны завершаться
   отказом.
7. Проверьте draft, publish, restore, перезапуск и сохранение прежнего активного
   снимка при ошибке.
8. Для каждой области проверьте наследование, замену, явное пустое значение и
   reset. Неизвестная область и пустая обязательная область должны отказать до
   фиксации ревизии.

Системный шаблон является версионированным файлом пакета. Пользовательский
макет хранится в БД и может переопределить системный согласно явному правилу
приоритета. Setting выбирает допустимый вариант, но не копирует всю страницу.

Страница входа — первый принятый пример этого пути:
[разбор `/admin/login`](/cms/login-composition/).
