# Разработка на Larena

> **Для кого:** разработчик. **Результат:** выбрать практический путь и не выйти
> за проверенную границу. **Источники:** Root developer docs и package contracts.
> **Статус:** первая редакция.

1. Подготовьте и проверьте entry-приложение.
2. Проследите путь личности и права.
3. Проверьте тип поля, запись и представление.
4. Зафиксируйте границу, где текущий публичный workflow заканчивается.

Начните со сценария [«Каталог материалов»](/development/materials-catalog/).
Он показывает, как связаны установка, личность, право, тип поля, запись,
представление и административная композиция.

Для отдельного контракта используйте [справочник пакетов](/packages/). Перед
добавлением нового расширения проверьте [стандарты и границы](/standards/).
