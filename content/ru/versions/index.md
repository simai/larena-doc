# Версии и ограничения

> **Для кого:** любой читатель. **Результат:** понять, к какой сборке относятся
> инструкции. **Источник:** Git, Composer lock и core-12 traceability.
> **Статус:** проверено 14 сентября 2026 года.

`6eaccb10c8550e877e391f8d441e811bfcb693ac`.

Документируемые проектные источники:

- Larena Specs: `044124944750fa2cefef1b2db659975e94ad6f9f`;
- Larena Workspace: `749cd11e1844cff40a7c768002737cb8c85aaaf7`;
- Larena entry app: `98dd55f2ea4bc8428907d386d7949633d6b8115e`.

Точные ревизии двенадцати пакетов записаны в repository source map. Текущий
Root — локальный release-candidate contour. Он не заявляет production readiness,
полноту frontend или готовность всего портфеля Larena.

## Обозначения готовности

| Метка | Смысл |
| --- | --- |
| Проверено | Есть актуальная проверка конкретного поведения в зафиксированной сборке |
| Developer-testable | Контракт можно проверять разработчику; стабильность публичного продукта не заявлена |
| Foundation | Реализована ограниченная основа, дальнейшие поверхности остаются отдельной работой |
| Pre-codegen | Активная реализация пакета ещё не начата |
| Проектируется | Идея или требование существует, но инструкция по использованию не публикуется |

Известные пробелы отражены непосредственно на страницах пакетов и в локальном
`docs/gaps.md`. При изменении одной из исходных ревизий документация требует
проверки актуальности, но не механического переписывания всех страниц.
