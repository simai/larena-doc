# Версии и ограничения

> **Для кого:** любой читатель. **Результат:** понять, к какой сборке относятся
> инструкции. **Источник:** Git, Composer lock и манифест сборки.
> **Статус:** проверено 18 ноября 2026 года.

Сайт собран на Docara `3.9.0` (revision
`ea984908fbfa1c53679dc7a2efb98c688ec9ac74`). Более новая версия движка
проверяется отдельно и не подменяет эту зафиксированную сборку.

Документируемые проектные источники:

- Larena Specs: `07153cd4b`;
- Larena Workspace: `31dccda30`;
- Larena entry app: `ee49efc9`.

Entry app собирает 26 пакетов Larena; их точные ревизии записаны в
`release/developer-alpha-manifest.json`. Бесплатный дистрибутив ставит 24 из
них: закрытые пакеты `larena/cockpit` и `larena/update` в него не входят.
Архивы пакетов дистрибутива с контрольными суммами записаны в
`composer.distribution.lock`. Интерфейс собран на бесплатном выпуске SIMAI
Framework `ui-7fb26d395af2` и наборах компонентов `pro-db490626ba74` (собран из
`simai/ui-pro`) и `chart-58ba480db497` (графики, из `simai/ui-chart`); сборка
поставляет их вместе с сайтом и не загружает с внешних адресов.

Текущий Root — локальный release-candidate contour. Он не заявляет production
readiness, полноту frontend или готовность всего портфеля Larena.

## Лицензии

Открытая часть Larena — приложение и открытые пакеты — распространяется по
Apache-2.0; платные пакеты — по коммерческой лицензии SIMAI. Текст этой
документации — CC BY 4.0, примеры кода в ней — Apache-2.0. Автор и
правообладатель — Рим Забаров. Наборы компонентов поставляются внутри
сборки; их условия указаны в манифесте выпуска.

## Обозначения готовности

| Метка | Смысл |
| --- | --- |
| Проверено | Есть актуальная проверка конкретного поведения в зафиксированной сборке |
| Developer-testable | Контракт можно проверять разработчику; стабильность публичного продукта не заявлена |
| Foundation | Реализована ограниченная основа, дальнейшие поверхности остаются отдельной работой |
| Pre-codegen | Активная реализация пакета ещё не начата |
| Проектируется | Идея или требование существует, но инструкция по использованию не публикуется |

Известные пробелы отражены непосредственно на страницах пакетов и в локальном
`docs/gaps.md`. При изменении одной из исходных ревизий документация требует
проверки актуальности, но не механического переписывания всех страниц.
