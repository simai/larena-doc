# Хранилища: руководство администратора

> **Для кого:** администратор сайта. **Результат:** вы умеете найти хранилище,
> работать с его записями, настраивать поля и переносить данные. **Источники:**
> решения по разделу «Хранилища» в Larena Specs, пакеты Admin и Storage.
> **Статус:** проверено по коду 26.10.2026 (на рабочем стенде — 22.10.2026);
> это developer-контур, вид экранов ещё может меняться.

Хранилище — это таблица со своими полями: например, «Клиенты» с полями «Имя»,
«Телефон» и «Статус». Строка такой таблицы называется записью. Раздел находится
по адресу `/admin/storage`.

## Найти и открыть хранилище

1. В меню откройте «Данные» → «Хранилища». Откроется список хранилищ с
   колонками «Название», «ID хранилища», «Полей», «Версия» и «Состояние».
2. Нажмите на название хранилища — откроется список его записей.

Каждое хранилище есть и отдельной строкой в меню «Данные».
Ещё быстрее — поиск админки (⌘K): он находит и хранилища, и записи в них.

Хранилища в архиве по умолчанию не показываются. Чтобы их увидеть, нажмите
«Показать архив».

## Список записей

### Порядок

Пока вы не выбрали сортировку, новые записи стоят сверху. Над списком в этом
случае написано: «Сортировка: дата создания, сначала новые.» Чтобы
отсортировать по полю, нажмите на заголовок колонки; повторное нажатие меняет
направление.

### Поиск

Введите слова в поле «Поиск». Поиск ищет по началу слов в полях, у которых
включено «Участвует в поиске»:

- «стол» найдёт «Стол» и «столы», но не «застолье»;
- если слов несколько, найдутся записи, где есть все эти слова, в любом
  порядке и в любых полях с поиском.

Запрос — не длиннее 100 символов. Если поле не находится поиском, проверьте,
включено ли у него «Участвует в поиске» (раздел «Поля хранилища» ниже).

### Фильтры

1. Нажмите «Фильтр».
2. На вкладке «Поля» выберите поле и значение.
3. Нажмите «Применить». «Сбросить» убирает фильтры.

Поля «Ссылка» в фильтре не предлагаются.

Набор поиска, фильтров, сортировки и колонок можно сохранить как «Вид» и
потом выбирать его из списка. Администратор может сохранить вид для всех, кто
работает с этим хранилищем.

### Колонки

Нажмите на значок настроек в заголовке таблицы. В панели можно:

- отметить, какие поля показывать;
- перетащить поля, чтобы поменять порядок колонок;
- закрепить колонку;
- нажать «Сбросить», чтобы вернуть как было.

Эти настройки сохраняются только для вас.

### Сколько записей найдено

В большом хранилище число найденных записей считается примерно. Тогда над
списком написано «Найдено примерно ~N записей.» Нажмите «Посчитать точно»,
если нужно точное число.

Если хранилище очень большое и список ещё строится, вы увидите «Список
готовится». Обновите страницу через несколько минут.

### Медленная сортировка

Сортировка большого хранилища по полю без быстрой сортировки идёт медленно.
Над списком тогда появится подсказка: «Сортировка по полю «…» на большом
хранилище идёт медленно» — и совет:

- «Включите для поля «Быстрая сортировка и фильтр»» — для короткой строки;
- задать полю максимальную длину до 255 символов — для длинной строки.

Совет ведёт в настройки поля; менять их может только администратор.

## Создать или изменить запись

### Создать

1. Нажмите «Создать». Если в хранилище есть поля «Запись хранилища», у кнопки
   есть стрелка: «Запись» создаёт запись этого хранилища, а пункт с названием
   поля (например, «Раздел») — запись того хранилища, на которое поле
   ссылается.
2. Заполните поля. Обязательные отмечены звёздочкой.
3. Нажмите «Создать».

### Изменить

1. Нажмите на запись в списке — справа откроется панель записи.
2. Нажмите карандаш у одного поля или «изменить», чтобы править всю форму.
3. Нажмите «Сохранить».

Через меню строки («Посмотреть», «Редактировать») можно открыть запись сразу в
нужном режиме. Кнопка «Копировать ссылку» в панели даёт адрес записи, который
можно отправить коллеге.

### Если запись не сохранилась

- **Ошибка в поле.** Сообщение стоит прямо под полем, например «Нужно число,
  например 100,5 или 100.5.» Введённое не теряется: исправьте поле и сохраните
  ещё раз.
- **Запись изменил кто-то другой.** Вы увидите: «Запись изменили, пока вы её
  правили. Ваши значения остались в форме — сохраните ещё раз, чтобы записать
  их поверх текущей версии.»
- **Закрываете панель с несохранёнными правками.** Сайт спросит «Закрыть?
  Введённое не будет сохранено.» Откажитесь, чтобы вернуться к правкам.

### История версий

Каждое сохранение — новая версия записи. Внизу панели откройте «История
версий»: там номер версии, время, что произошло и кто это сделал.

Чтобы вернуть старые значения, нажмите «Вернуть» у нужной версии. Они станут
текущими, а нынешние останутся в истории — ничего не теряется.

Сколько версий хранить, задаётся в «Свойствах хранилища», поле «Хранить
изменений». Пусто — хранятся все. Текущая и опубликованная версии не удаляются
никогда.

## Архив и удаление навсегда

### Записи

1. Чтобы убрать запись в архив, нажмите в её панели «В архив» и подтвердите.
2. Чтобы убрать сразу несколько, отметьте их в списке и выберите «В архив».
   Пункт «Для всех (N)» убирает все записи под текущим фильтром — до 1000 за
   раз.
3. Архив открывается через меню списка (⋮) → «Архив записей».
4. В архиве в меню строки есть «Восстановить» и «Удалить навсегда».

Удаление навсегда необратимо: вместе с записью удаляются все её версии. Сайт
сначала спросит «Удалить запись навсегда? Вернуть её будет нельзя.»

### Хранилище

1. Откройте настройки хранилища: меню списка (⋮) → «Настройки».
2. Внизу нажмите «Перенести хранилище в архив», отметьте «Подтверждаю перенос в
   архив» и нажмите «В архив». Записи сохранятся, но менять их будет нельзя.
3. Найти такое хранилище можно через «Показать архив». В его настройках есть
   «Восстановить хранилище» и «Удалить хранилище навсегда».
4. Для удаления навсегда введите ID хранилища. Хранилище и все его записи
   удалятся без возможности восстановления, а этот ID нельзя будет использовать
   снова.

## Создать хранилище

1. В меню «Данные» нажмите «Создать хранилище».
2. Заполните «Название» и «ID хранилища». ID начинается с `workbench.`,
   например `workbench.clients`, и потом не меняется.
3. При желании укажите «Группа в меню» — подпись, под которой хранилище
   появится в «Данных».
4. Нажмите «Создать», затем добавьте поля в настройках.

## Поля хранилища

### Добавить поле

1. Откройте «Настройки» хранилища.
2. Нажмите «Создать» над списком полей — откроется «Добавить поле».
3. Укажите «Название», «Ключ» (латиница, цифры и `_`, начинается с буквы) и
   «Тип».
4. Настройте то, что предлагает выбранный тип, и нажмите «Создать».

Форма показывает только настройки выбранного типа. Некоторые из них задаются
один раз, при создании поля, — у такой настройки есть подсказка «Задаётся при
создании поля и потом не меняется.»

Новое поле в хранилище, где уже есть записи, может быть только необязательным.

### Типы полей

| Тип | Что хранит |
| --- | --- |
| «Строка», «Текст» | короткий и длинный текст |
| «Целое число», «Число» | числа; число можно вводить через запятую: «100,5» |
| «Да/нет» | флажок |
| «Дата», «Дата и время» | дата или дата со временем, во времени сайта |
| «Выбор из списка» | один вариант из списка |
| «Несколько из списка» | несколько вариантов из списка |
| «Пользователь», «Файл» | пользователь сайта или файл |
| «Запись хранилища» | ссылка на запись другого хранилища |
| «Связь» | связанный материал |
| «Выбор из справочника» | значение из справочника сайта, например часового пояса |
| «Цвет» | цвет, выбирается в палитре |
| «Телефон» | номер телефона с кодом страны |
| «Адрес страницы» | адрес в интернете |
| «Ссылка» | адрес с подписью; пока только для чтения, см. ниже |

Для «Выбора из списка» и «Нескольких из списка» варианты пишутся по одному на
строку: `значение | Название | цвет | значок`. Можно написать только название.
Цвет — `primary`, `secondary`, `success`, `warning`, `error`, `info`, `neutral`
или `#RRGGBB`; значок — имя значка, например `star`.

Для «Записи хранилища» выберите, на какое хранилище ссылается поле: начните
вводить название, и список подскажет. После создания поля это не меняется.

Для «Выбора из справочника» укажите «Справочник» — откуда брать варианты. Для
«Телефона» можно задать «Страну по умолчанию»: номер без кода страны будет
считаться номером этой страны (номер с «+» читается как есть).

Поле «Ссылка» в панели записи пока показывается только для чтения: элемента
для ввода ссылки во Framework ещё нет.

### Настройки поля

- «Обязательное» — без значения запись не сохранится.
- «Скрыто» — поле не показывается в списке и не попадает в экспорт.
- «Максимальная длина» — сколько символов может быть в строке; пусто — без
  ограничения.
- «Участвует в поиске» — поле ищется поиском списка. Для «Строки», «Текста» и
  «Телефона».
- «Быстрая сортировка и фильтр» — список быстро сортируется и фильтруется по
  этому полю даже на миллионах записей. Только для «Строки» с максимальной
  длиной не больше 255; в одном хранилище — не больше 40 таких полей.
- «Переводится на другие языки» — у поля может быть своё значение для каждого
  языка сайта. Для «Строки» и «Текста».
- «Шифровать» — см. раздел «Шифрование полей» ниже.

### Изменить, удалить или сменить тип поля

Нажмите на поле в настройках и измените нужную настройку карандашом.

Настройки, которые меняют только вид формы — маска ввода, подсказка в поле,
шаг, единица измерения, — сохраняются сразу.

Если изменение затрагивает уже сохранённые записи (смена типа, длины,
вариантов, обязательности, шифрования), сайт сначала проверяет записи:

1. Сохраните изменение. В строке сохранения появится вопрос, например «Новые
   настройки затронут данные: проверено 120 из 120 записей, не подходят 0.»
2. Подтвердите изменение в этой строке.

Если какие-то записи не подходят, изменение не выполняется. Сайт скажет,
сколько их, и назовёт несколько ID. Исправьте эти записи или выберите другие
настройки.

- **Удалить поле:** в меню строки поля выберите удаление и подтвердите
  «Удалить поле «…»? Его значения будут удалены из всех записей хранилища.»
  Вернуть значения возвратом старой версии записи нельзя.
- **Сделать обязательным:** отметьте «Обязательное» в списке полей. Сайт
  скажет, сколько записей пока без значения; пока такие есть, сохранить это
  нельзя.
- **Большое хранилище** (больше 5000 записей) меняется в фоне: вы видите
  «Меняем поле …: проверено N из M», а список работает как обычно. Пока поле
  меняется, другие поля менять и архивировать хранилище нельзя. Кнопка
  «Отменить изменение» оставляет поле и записи прежними.

## Экспорт и импорт CSV

Все действия — в меню списка записей (⋮).

### Быстрый экспорт

Выберите «Экспорт CSV (видимые колонки)». В файл попадут записи, которые
показывает список, с его поиском, фильтрами и сортировкой, в тех колонках и в
том порядке, что вы видите. Не больше 10 000 строк. Первой колонкой идёт ID
записи.

### Экспорт в фоне

Для большого хранилища:

1. Выберите «Экспорт CSV в фоне (все поля)». Откроется страница «Фоновые
   задачи».
2. Нажмите «Выгрузить CSV».
3. Когда задача станет «Готово», нажмите «Скачать».

В файле все поля, кроме скрытых и зашифрованных. Скачать его можете только вы.

### Импорт

На стенде уже есть «Импорт CSV»:

1. Выберите «Импорт CSV», укажите файл и нажмите «Проверить файл».
2. Посмотрите, что изменится: сколько записей добавится, изменится и останется
   без изменений, и ошибки по строкам.
3. Если ошибок нет, нажмите «Импортировать».

Строка с ID существующей записи обновляет её, строка без ID добавляет новую.
Поля-ссылки (пользователь, файл, запись) пока не импортируются. Большой файл
записывается в фоне; ход виден на странице «Фоновые задачи».

## Перенести хранилище на другой сайт

Перенос берёт структуру хранилища и все записи с переводами, публикацией и
файлами. История изменений не переносится.

### Выгрузить

1. Откройте «Настройки» хранилища, блок «Перенос на другой сайт».
2. Нажмите «Выгрузить хранилище».
3. Когда в «Ваших выгрузках» появится «Готово», нажмите «Скачать».

Архив видите и скачиваете только вы; через несколько дней он удаляется.

### Загрузить

1. В списке хранилищ нажмите «Загрузить хранилище».
2. Выберите файл архива (.zip) и нажмите «Загрузить архив».
3. Сайт проверит архив и покажет, что будет создано. Пока вы не нажмёте
   «Загрузить», на сайте ничего не меняется.
4. В «Настройках загрузки» при необходимости поправьте «Название» и «ID
   хранилища». Если записи ссылаются на другие хранилища, в «Куда ведут ссылки»
   выберите, в каком хранилище этого сайта их искать. Нажмите «Проверить
   снова».
5. Нажмите «Загрузить». Пока идёт загрузка, видно «n из N записей» и кнопку
   «Отменить»; если загрузка остановилась — причину и «Повторить».

Записи по умолчанию приходят черновиками («Как черновики (рекомендуется)»).
Тот, у кого есть право публиковать, может выбрать «Сохранить публикацию». Если
этот архив уже загружали, его можно загрузить только копией — записи получат
новые ID.

## Шифрование полей

Опция «Шифровать» хранит значение поля в базе зашифрованным. Если база утечёт,
значения нельзя будет прочитать.

- Шифровать можно поля «Строка», «Текст», «Целое число», «Число», «Дата» и
  «Дата и время».
- Зашифрованное поле нельзя искать, сортировать и фильтровать. Оно видно только
  в админке: на сайт, в поиск и в публичные списки не попадает.
- В списке вместо значения — «•••• зашифровано».
- Чтобы увидеть значение, нажмите «Показать» в панели записи. Это может только
  администратор, и каждый просмотр записывается в журнал аудита.
- Редактор может заменить значение, не читая его: введите новое; пустое поле
  оставляет прежнее.

Если включить шифрование у поля, где уже есть значения, отметьте «Подтверждаю
включение шифрования». Уже сохранённые значения, включая историю, зашифруются в
фоне. Старые резервные копии базы и журналы MySQL всё ещё содержат открытые
значения. Чтобы выключить шифрование у такого поля, отметьте «Подтверждаю
расшифровку»: значения расшифруются в фоне и снова будут храниться открыто.

На странице настроек администратор видит блок «Шифрование»: состояние ключа и
кнопку «Сменить ключ шифрования». Если работа с ключом остановилась, её
продолжает «Повторить».

При экспорте CSV и переносе на другой сайт зашифрованные значения не
выгружаются. При переносе их можно включить в открытом виде отметкой «Включить
зашифрованные поля в открытом виде» — если у вас есть право их читать. Такой
архив храните как секретный документ.

## Публикация на сайте

В разделе «Хранилища» записи не публикуются. Публикация делается в «Данные» →
«Страницы сайта»:

- «Опубликовать» и «Снять с публикации» — для каждого языка;
- «Запланировать» — выпустить новую версию в выбранное время. До этого момента
  на сайте остаётся прежняя версия: «Опубликовано · запланирована новая версия
  на …».

### Список записей на странице сайта

1. В «Страницах сайта» откройте меню страницы → «Список записей».
2. Добавьте список: выберите «Хранилище», «Сортировку» и «Порядок», «Записей на
   странице» (до 100).
3. При желании задайте «Показывать записи со словами» и «Отбор по полю».

Список показывает только опубликованные записи и только публичные поля.
Удаление списка со страницы не трогает записи в хранилище.

## Кто что может

| Роль | Что может в «Хранилищах» |
| --- | --- |
| Администратор | всё: создаёт хранилища, настраивает поля, удаляет навсегда, переносит хранилища, управляет шифрованием и читает зашифрованные поля |
| Редактор | работает с записями: создаёт, меняет, убирает в архив и восстанавливает, смотрит историю; не видит настроек полей и не удаляет навсегда |
| Читатель | только смотрит записи и их историю |

Если прав не хватает, кнопки нет, а прямое действие отклоняется с сообщением
«Недостаточно прав для этого действия.»

## Чего пока нет

- Публикации записей прямо из раздела «Хранилища».
- Импорта полей-ссылок (пользователь, файл, запись) из CSV.
- Переноса истории версий на другой сайт.
- Поиска, сортировки и фильтра по зашифрованным полям.
- Ввода и фильтра для полей «Ссылка»: в панели записи они только для чтения.
- Ввода даты с клавиатуры: пока дату выбирают в календаре.
