# Установить сайт

> **Для кого:** владелец сайта или тот, кто ставит сайт по его просьбе.
> **Результат:** сайт работает, вы вошли в админку. **Источники:** скрипты
> установки Root и мастер первого запуска пакета Admin. **Статус:** проверено по
> коду 18.11.2026.

Поставить Larena можно двумя способами. Установщика, который открывается в
браузере, нет.

- **Larena Panel** — бесплатная панель для своего сервера. Она ставит сайт в
  той же раскладке папок, что и скрипт ниже.
- **Один скрипт** — для тех, кто привык работать в консоли сервера.

## Что нужно на сервере

- PHP 8.3 или новее с расширениями PDO, OpenSSL и mbstring;
- Git: скрипт запускается из копии репозитория Larena;
- база: по умолчанию SQLite, её создаёт сам скрипт. Для MySQL 8 или 9 базу
  создайте заранее, пустой, а параметры подключения передайте файлом,
  который может читать только владелец; скрипт базы не создаёт и не удаляет.

## Установка одним скриптом

1. Возьмите копию репозитория Larena нужной версии.
2. Выберите пустую папку для сайта, например `/var/www/example`.
3. Запустите скрипт, указав полный путь к этой папке:

   ```bash
   ./scripts/install-larena-site.sh /var/www/example
   ```

4. Ответьте на вопросы о первом администраторе: почта, имя и пароль. Пароль —
   не короче 12 символов и хотя бы с одним специальным знаком. Он нигде не
   сохраняется.

Если установку прервали, запустите ту же команду ещё раз — она продолжит с
места остановки. Если сайт в папке уже стоит, скрипт ничего не меняет и
сообщает об этом: обновлять сайт нужно не им.

### Что получится в папке сайта

| Что | Зачем |
| --- | --- |
| `releases/<версия>/` | код одной версии сайта |
| `current` | ссылка на работающую версию |
| `.env` | настройки сайта, общие для всех версий |
| `storage/` | загруженные файлы, копии, журналы — общие для всех версий |
| `database/` | база SQLite (при MySQL этой папки нет) |

Новая версия ставится рядом в `releases/`, а переключение — это смена ссылки
`current`. Ваши данные и файлы лежат вне версий и при переключении не
трогаются.

### Последние три шага

В конце скрипт выводит три строки. Сделайте по ним:

1. **Веб-сервер.** Корневая папка сайта — `<папка сайта>/current/public`.
2. **Планировщик.** Добавьте в cron задачу, которая раз в минуту запускает
   `php <папка сайта>/current/artisan schedule:run`.
3. **Очередь.** Держите запущенным `php <папка сайта>/current/artisan
   queue:work` (например, как службу). Через очередь идут фоновые работы:
   резервные копии, выгрузки, большие изменения хранилищ.

Без планировщика и очереди сайт откроется, но фоновые работы будут стоять «в
очереди».

## Первый запуск

Если администратора создали при установке, сразу откройте `/admin/login` и
войдите.

Если сайт поставили без администратора, откройте `/admin/setup` — это мастер
первого запуска «Установка Larena». Он открывается только до появления первого
администратора, показывает по одному шагу на странице и наверху — все шаги с
их состоянием:

1. **Проверка** — версия PHP, расширения, папки для записи и база. Здесь
   ничего не меняется.
2. **Администратор** — ваше имя, почта, пароль и его подтверждение.
   Администратор создаётся вместе с сайтом, на следующем шаге.
3. **Сайт** — «Название сайта», «Язык по умолчанию» (русский или английский)
   и «Часовой пояс». Здесь же можно отметить «Установить демо-данные»: каталог
   с примерами всех типов полей. Его потом можно удалить, как любое хранилище.
   Нажмите «Создать сайт».
4. **Готово** — нажмите «Войти».

Получится сайт с редактируемой страницей «Главная».

## Первые шаги

На главной странице админки после входа ждёт список «Первые шаги» со счётчиком
«сделано N из M»:

- **Адрес и HTTPS** — свой домен и защищённое соединение;
- **Первая страница** — главная и разделы сайта;
- **Пригласите людей** — редакторы и администраторы со своим входом;
- **Вход с кодом** — двухфакторная проверка для входа в админку.

У каждого пункта своя кнопка, она открывает нужный раздел. Кнопка «Скрыть»
убирает список с главной только для вас.

## Если что-то не так

- Скрипт пишет, что папка не пустая, — выберите пустую папку.
- Мастер пишет «Администратор уже существует, поэтому начальная настройка
  закрыта» — это нормально: войдите через `/admin/login`.
- Мастер остановился — изменения не применены, условия можно исправить и
  повторить.
