# Файлы и картинки

> **Для кого:** владелец сайта и редактор. **Результат:** нужные картинки и
> документы загружены, лежат по папкам и доступны там, где они нужны.
> **Источники:** пакеты File Manager и Filesystem. **Статус:** проверено по
> коду 17.11.2026.

Раздел находится в «Данные» → «Файлы» (`/admin/files`).

## Что можно загрузить

- картинки JPEG, PNG и WebP;
- документы PDF и текстовые файлы.

Один файл — до 10 МБ. Этот предел может поменять тот, кто обслуживает сервер.

## Загрузить файл

1. Откройте папку, куда положить файл, или «Все файлы».
2. Нажмите «Загрузить файл» и выберите файл. Можно просто перетащить файлы в
   окно.
3. Откройте файл и заполните:
   - «Название» — как файл называется в админке;
   - «Альтернативный текст» — короткое описание картинки для тех, кто её не
     видит, и для поисковиков;
   - «Видимость» — «Публичный» или «Закрытый».
4. Нажмите «Сохранить».

**Публичный** файл открывается по своему адресу — его видно в поле
«Публичный адрес». **Закрытый** файл виден только в админке.

## Папки

- «Новая папка» — создать папку внутри открытой.
- «Настроить папку» — переименовать.
- Файлы между папками переносят перетаскиванием.
- «Удалить папку» — только пустую: сначала перенесите или удалите её файлы и
  вложенные папки.

## Заменить, вернуть, удалить

- «Заменить файл…» загружает новое содержимое на место старого. Адрес файла
  не меняется, прежнее содержимое остаётся в «Истории версий».
- В «Истории версий» нажмите «Вернуть» у нужной версии. Нынешнее содержимое
  сохранится как новая версия — ничего не теряется.
- «Удалить» отправляет файл в корзину.

## Где используются файлы

- **В записях хранилищ.** К записи [хранилища](/cms/storage/) с полем-файлом
  прикладывают файл прямо в панели записи («Выберите файл»).
- **На странице входа в админку.** В «Настройки» → «Сайты» → ваш сайт →
  «Картинка рядом с формой входа» можно поставить любое публичное изображение
  из «Файлов».

## Кто что может

Администратор и редактор загружают файлы, меняют их описание и раскладывают по
папкам. Удаляет файлы администратор. Читатель только смотрит.

## Ограничения сейчас

Раздел «Файлы» и публичные адреса файлов пока помечены как не готовые к
рабочему (production) сайту: они включаются, только когда сайт работает в
локальной или тестовой среде. Сайт, поставленный скриптом установки, работает
именно так, поэтому раздел в нём есть. Это пока не полноценная медиатека, а
простое хранилище файлов.
