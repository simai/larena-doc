# Страницы и дерево сайта

> **Для кого:** владелец сайта и редактор. **Результат:** на сайте есть нужные
> страницы в нужном порядке, и они опубликованы. **Источники:** пакеты Admin,
> Storage и Layout, маршруты сайта в Root. **Статус:** проверено по коду
> 17.11.2026.

Страницы сайта образуют дерево: у каждой страницы есть место, а её адрес
складывается из адресов страниц выше. Например, страница «Доставка» с адресом
`delivery` внутри страницы «Покупателям» (`buyers`) открывается по адресу
`/buyers/delivery`.

Раздел находится в «Данные» → «Страницы сайта» (`/admin/site/pages`).

## Создать страницу

1. Нажмите «Создать страницу». Чтобы создать её сразу внутри другой, откройте
   меню той страницы → «Новая страница внутри».
2. Заполните «Заголовок» и «Адрес». Адрес — латинские буквы, цифры, «-» и
   «_», начинается с буквы или цифры.
3. Выберите «Содержимое»: «Текст» — обычный текст страницы, «Блоки» — страница
   из блоков (о них ниже).
4. Сохраните.

Новая страница — черновик: на сайте её ещё нет.

Некоторые адреса заняты самой системой, например `admin` или `api`. Сайт
подскажет, если адрес занят.

## Дерево страниц

- **Переместить.** В меню страницы → «Переместить» и выберите нового
  родителя или «Верхний уровень». Всё, что внутри страницы, переедет вместе с
  ней. Перед изменением сайт покажет, что произойдёт, и попросит подтвердить.
- **Переименовать** — меняет название страницы.
- **В архив** — убирает страницу. Опубликованную страницу сначала снимите с
  публикации на всех языках.

**Главная** всегда стоит на адресе `/`: пока она опубликована, её адрес и
место не меняются.

Если у страницы изменился адрес, сайт сам добавит переадресацию со старого
адреса на новый, чтобы старые ссылки не вели в никуда.

## Публикация

Публикация делается отдельно для каждого языка. В меню страницы:

- «Опубликовать» — страница появляется на сайте;
- «Снять с публикации» — страница пропадает с сайта, но остаётся в админке;
- «Запланировать» — выпустить новую версию в указанное время («Опубликовать
  в»). До этого момента на сайте остаётся прежняя версия: «Опубликовано ·
  запланирована новая версия на …».

Состояния страницы: «Черновик», «Запланировано», «Опубликовано», «В архиве».
Публикует администратор; редактор готовит страницы.

Пока страница выше не опубликована, вложенные в неё страницы на сайте тоже не
открываются.

## Блоки страницы

Если у страницы «Содержимое» — «Блоки», в её меню есть «Блоки». Нажмите
«Добавить блок» и выберите вид:

- **Текст** — абзацы текста;
- **Меню** — список ссылок на страницы сайта, см.
  [меню и языки](/cms/menus-languages/);
- **Список записей** — записи из хранилища, например новости или каталог.

У каждого блока есть «Место в списке»: номер сверху, остальные подвинутся.
Изменение блоков — новая версия страницы: сайт покажет её после публикации.

## Список записей на странице

Чтобы показать на странице записи хранилища:

1. В меню страницы → «Список записей» → «Добавить список записей».
2. Выберите «Хранилище», «Сортировку» и «Порядок», «Записей на странице» (до
   100).
3. При желании задайте «Показывать записи со словами» и «Отбор по полю».

Список показывает только опубликованные записи и только публичные поля.
Удаление списка со страницы не трогает записи в хранилище.

## Страница для каждой записи

Если нужно, чтобы у каждой записи хранилища был свой адрес (например, у
каждой новости), откройте страницу-раздел и в поле «Выдаёт записи» выберите
хранилище. Каждая опубликованная запись получит адрес внутри этой страницы.
Записи одного хранилища может выдавать только одна страница.

## Шапка, подвал и боковая колонка

Вокруг страниц стоят общие области: «Шапка», «Подвал» и «Боковая колонка».
Их блоки настраиваются в карточке сайта: «Настройки» → «Сайты» → ваш сайт →
«Области вокруг страниц сайта». Раздел или страница могут заменить эти блоки
своими; пустой список значит, что блоки берутся сверху. Изменения областей
ждут черновиком, пока их не опубликуют в «Черновики и публикация».
